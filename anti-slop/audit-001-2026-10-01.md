# antislop audit 001: Vigan City Records frontend

Date: 2026-10-01
Mode: AFTER (audit first; nothing is changed until specific numbers are approved)
Scope: `frontend/src` (pages, components, `styles/adminator.css`, `styles/workspace.css`)
Method: code inspection plus contrast measurement with `antislop-human/contrast-check.py`. The app was not clicked through in a browser for this audit (see #6).

Priority follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

## Findings

### HIGH (Hard Gate)

1. **No design direction file** (R-37, R-31, Liveliness dials). There is no `DESIGN.md`. The real direction exists only as decisions made in chat: monochrome chrome, emerald dark mode, Libre Franklin plus Source Sans 3, Okabe-Ito chart palette, office colors kept for icons and charts only. No ENERGY / RHYTHM / MOTION dials are declared. Fix: transcribe those owner decisions (no invented content) into `DESIGN.md` with dials, for the owner to confirm.

2. **Text below WCAG AA contrast** (R-25). `--t-light` (#94A3B8) is used for real text: chart axis labels, input placeholders, the "Ctrl K" hint, footer meta, muted notes. Measured 2.56:1 on white and 2.35:1 on the page background (needs 4.5:1). The light chart greys used as text-adjacent labels (#B8BEC8 1.87:1, #D5D9DF 1.42:1) also fail if used for text. Fix: darken `--t-light` for light mode to at least 4.5:1 (for example #6B7280, 4.83:1) and keep the pale greys for non-text marks only.

3. **Focus indicator removed on search fields** (R-32). `.ws-list-search input` (Office workspaces, Offices), `.ws-picker-search input` (office dropdown) set `outline: 0` with no `:focus-within` replacement on their wrapper, so keyboard users cannot see focus there. There is also no shared `:focus-visible` style for the custom buttons (chips, cards, list rows, segmented control), which rely on the browser default and become hard to see on the dark rail. Fix: a focus ring on those wrappers and one global `:focus-visible` ring token.

4. **Em dash in UI text** (R-02). 9 occurrences: 3 inside sentences ("correct it in Citizens — it's shared…", "Sample data — not real records", "Tell your office's story with a chart — e.g. …") and 6 used as the empty-value placeholder (Overview KPIs, office Home counts, Insights drill-down, intake review). Fix: rewrite the sentences with a comma or period; replace the placeholder with "Not on file" or a plain hyphen-free label.

5. **Missing error states** (R-27). 13 fetches swallow errors into an empty value. The worst: the Overview shows a spinner forever when its data call fails (`if (!data) return spinner`), and the office Home shows the "Build a chart" prompt when loading charts fails, which reads as "you have no charts". Fix: an error state with the cause and a Retry action on Overview, office Home charts, Office workspaces and the Visualizations board.

6. **No recorded click-through** (R-35). Builds pass, but no screen has been clicked through in a browser with a signed-in session (sign-in was blocked for the agent). Fix: run the app signed in as admin and as one office staff account and record the click-through element by element.

7. **Search disappears on small screens** (R-03). Below 900px the top-bar search is `display: none` with no replacement, so phone and tablet users lose search (and Ctrl+K has no target). Mobile breakpoints are otherwise unverified. Fix: collapse search into an icon button that opens it; verify 360px and 768px layouts during #6.

### MEDIUM (Purpose-Gate)

8. **Uppercase tracked labels with no written reason** (R-06). Sidebar section labels, eyebrows ("25 HOUSEHOLDS", the date on office Home), staff table headers, base table headers, "Manage office" section titles, the brand tag. Fix: write the reason where it is real (navigation grouping, scannable table columns) in `DESIGN.md`, and switch the rest (eyebrows, manage titles) to sentence case.

9. **Icon set has the default library look** (R-04). The hand-drawn set uses 1.8 to 1.9px rounded strokes, the same look as Lucide, chosen by default. Office icons are relevant (sprout, heart, coins, paw) but the relevance and the stroke choice are not written down. Fix: document per-icon relevance and decide the stroke and weight as an identity choice, or keep the set with a written reason.

10. **Text glyphs mixed in as icons** (R-04). "✓ On dashboard", "✓" in the intake stepper, "✕" on filter chips, "▲ / ▼" on the KPI delta, next to the SVG icon set. Fix: use the set's SVG check, x and trend icons, with accessible labels.

### LOW (Quality Locks)

11. **Overview is the default dashboard shell** (R-05, C-3). KPI row, stacked bar chart, donut, ranking: the layout came before naming the screen's job. The donut repeats what the stacked bars already show. Fix: name the decision the Overview supports and order the sections by it; drop or merge the donut.

12. **Office hues exceed the palette cap** (R-29). 16 office hues on sidebar tiles, office cards and chart dots, plus the 6-color chart set. At 30 to 40 offices the hues repeat and stop identifying offices. Fix: keep the hue only on the office tile inside that office's context; elsewhere show the icon and short name in neutral; cap categorical hues.

13. **Pill radius on many element types, inline radii scattered** (R-11). Chips, status pills, segmented control, office chips and badges are all 999px; inline styles add 6, 8, 10, 12 and 14px radii. Fix: radius tokens (small, medium, large, pill for chips and segments only) and replace the inline values.

14. **No identity motif** (R-20, Liveliness). With the logo swapped, the monochrome chrome and neutral cards could belong to any admin panel. The city seal is the only Vigan-specific element. Fix: the owner chooses one motif (for example a typographic voice or a heritage detail) and records it in `DESIGN.md`; not invented by the agent.

15. **Leftover CSS and inline-style drift** (R-31 support). `.ws-rail-filter`, `.ws-rail-group*`, `.ws-chev` are unused since the sidebar list was removed; many components set spacing, size and color inline, which makes the scale hard to keep consistent. Fix: remove dead rules; move repeated inline values to classes or tokens.

## What already passes

- No gradients, glassmorphism, glow, background grids or decorative status dots.
- Sample data is labelled ("Sample" tag on records, "Sample data" on charts) instead of passing as real (R-38).
- Avatars are initials, the logo is the real city seal (R-23).
- Theme toggle exists and dark mode was checked for text contrast (R-21, R-34 partly; full check in #6).
- Typeface choice has a written reason in `workspace.css` (R-06 for the families).
- Charts follow one palette, horizontal dashed grid, custom tooltip, donut cap of 5 (R-01, R-13).
